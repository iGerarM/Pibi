Configuration

To replace our design with your desired theme. Please do configuration as mention

Path : src > app > shared > services > layout.service.ts 

  
    public config = {  
      color: '{{layoutService.config.color}}',
      layout: '{{layoutService.config.layout}}',
      rtl: '{{layoutService.config.rtl}}',
      wallpaper: '{{layoutService.config.wallpaper}}',
      sidebar_type: '{{layoutService.config.sidebar_type}}',
      sidebar_setting: '{{layoutService.config.sidebar_setting}}',
    }
